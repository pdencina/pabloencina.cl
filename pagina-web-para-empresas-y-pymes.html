Preguntas frecuentes

Lo que preguntan las empresas antes de contratar

¿Cuánto cuesta una página web para mi empresa?

Una landing con lo esencial parte desde $149.000. Un sitio con varias páginas (inicio, servicios, nosotros y contacto) se cotiza según el alcance, y el valor queda por escrito antes de empezar.

¿Incluye correos con el nombre de mi empresa?

La conexión del dominio y el hosting se configuran. Los correos con tu dominio, con sus costos y accesos, se definen en la propuesta. Puedes ver cómo funcionan antes de decidir.

¿Qué pasa con la web que ya tengo?

Se puede rediseñar o migrar. Revisamos qué conviene conservar y se dejan redirecciones para no perder lo que ya tienes en Google.

¿Puedo pedirte cambios después de publicarla?

Sí. Puedes cotizar mejoras o mantención cuando las necesites, y el alcance se acuerda por escrito en cada caso.
