# Logo Pablo Encina — kit de archivos

## Favicon (pega esto en el <head> de tu web)
```html
<link rel="icon" href="/assets/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/assets/favicon-32.png" sizes="32x32" type="image/png">
<link rel="icon" href="/assets/favicon-16.png" sizes="16x16" type="image/png">
<link rel="apple-touch-icon" href="/assets/apple-touch-icon.png">
<link rel="manifest" href="/assets/site.webmanifest">
<meta name="theme-color" content="#0A0A0B">
<meta property="og:image" content="/assets/og-image.png">
```

## Archivos
- **favicon.svg / icono-pabloencina.svg** — ícono vectorial, fondo transparente. Úsalo siempre que puedas: se ve nítido en cualquier tamaño.
- **icono-pabloencina-claro.svg** — ícono para fondos claros (colores más saturados).
- **icono-pabloencina-blanco.svg** — ícono a una tinta blanca (sobre fotos, footer, marca de agua).
- **favicon-16/32/48/64/128/180/192/256/512/1024.png** — PNG transparentes del ícono.
- **apple-touch-icon.png** (180px) — con fondo negro, para iPhone/iPad.
- **icono-maskable-512.png** — para Android / PWA.
- **logo-horizontal-oscuro.png** — logo completo para FONDO OSCURO (texto blanco). Transparente.
- **logo-horizontal-claro.png** — logo completo para FONDO CLARO (texto negro). Transparente.
- **logo-apilado.png** — versión vertical, para espacios angostos.
- **logo-blanco.png / logo-negro.png** — versiones a una tinta (documentos, facturas, sellos).
- **og-image.png** (1200×630) — imagen que se ve al compartir tu web en WhatsApp / redes.

## Reglas rápidas
- Espacio libre alrededor del logo: al menos la altura de un módulo del ícono.
- Tamaño mínimo del logo horizontal: 140 px de ancho. Bajo eso, usa solo el ícono.
- No cambies el orden de los colores ni le pongas sombras o contornos.
- Nunca pongas el logo de color sobre fondos medios: usa la versión blanca o negra.
